# Tarefa 5 — Calculadora

Calculadora de duas entradas numéricas capaz de executar as quatro operações aritméticas básicas. O resultado é atualizado na própria página por meio de manipulação do DOM.

## Funcionalidades

- soma;
- subtração;
- multiplicação;
- divisão;
- leitura dos números informados nos campos;
- exibição do resultado sem recarregar a página.

## O que é praticado

- campos numéricos e botões em HTML;
- conversão dos valores recebidos pela interface;
- passagem do operador como argumento para uma função;
- condicionais para escolher a operação;
- manipulação de conteúdo no DOM;
- integração de estrutura, estilo e comportamento.

## Arquivos

- `index.html`: interface da calculadora;
- `style.css`: organização e aparência dos controles;
- `script.js`: função `calcular` e regras das operações.

## Como executar

Abra `index.html`, informe dois números e selecione uma operação. Não é necessário instalar dependências.

> A calculadora é um exercício didático executado integralmente no navegador; os dados não são persistidos.
