# Tarefa 3 — MeuBlog

Esta tarefa desenvolve a interface estática de um blog. A página possui cabeçalho com navegação, apresentação ao autor, uma grade com dez postagens recentes e rodapé.

## O que é praticado

- organização semântica com cabeçalho, navegação, conteúdo principal, seções e rodapé;
- criação de links para áreas da própria página;
- repetição de uma estrutura visual para representar postagens;
- layout de múltiplos cards com CSS;
- uso de seletores por elemento, classe e identificador;
- efeitos visuais e adaptação do conteúdo ao espaço disponível.

## Arquivos

- `index.html`: estrutura completa do blog e conteúdo das dez postagens;
- `style.css`: layout, tipografia, cores, navegação, cards e rodapé.

## Como visualizar

Abra `index.html` no navegador. Não é necessário instalar pacotes ou compilar o projeto.

## Resultado esperado

Uma página de blog organizada, com identidade visual consistente, área de boas-vindas e postagens distribuídas de forma clara.
