# HTML — Tags de mídia

Esta pasta demonstra como exibir imagem, áudio e vídeo diretamente em uma página HTML usando arquivos locais.

## Conceitos estudados

- imagem com `img`, caminho em `src` e texto alternativo em `alt`;
- áudio com `audio`, fontes e controles nativos;
- vídeo com `video`, dimensões e controles de reprodução;
- caminhos relativos entre o HTML e os arquivos da mesma pasta;
- alternativas de conteúdo quando o navegador não suporta a mídia.

## Arquivos

- `index.html`: incorpora as três mídias;
- `passaro_azul.png`: imagem local;
- `audio.mp3`: faixa de áudio local;
- `video.mp4`: vídeo local.

## Como visualizar

Abra `index.html` no navegador. Mantenha todos os arquivos na mesma pasta para que os caminhos relativos continuem funcionando.
