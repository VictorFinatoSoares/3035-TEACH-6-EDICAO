# HTML — Tags estruturais

Exemplo voltado à semântica da página. Em vez de organizar tudo com elementos genéricos, o conteúdo é dividido conforme a função de cada região.

## Conceitos estudados

- `header` para o cabeçalho;
- `nav` para a navegação;
- `main` para o conteúdo principal;
- `section` e `article` para agrupar conteúdos relacionados;
- `aside` para informações complementares;
- `footer` para o rodapé.

O uso dessas tags melhora a legibilidade do código, a acessibilidade e a interpretação da página por mecanismos de busca.

## Como visualizar

Abra `index.html` e compare a estrutura exibida com a marcação no código-fonte. Não há dependências.
