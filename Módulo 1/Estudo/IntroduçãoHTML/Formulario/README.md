# HTML — Formulários

Página de estudo dos principais controles de formulário oferecidos pelo HTML. O exemplo reúne campos de cadastro e demonstra como rótulos, tipos de entrada e validações nativas são declarados.

## Conceitos estudados

- associação entre `label` e campo por meio de `for` e `id`;
- entradas de texto, e-mail, senha, número, cor e arquivo;
- limites numéricos com `min` e `max`;
- campos obrigatórios com `required`;
- seleção com `select` e `option`;
- checkbox, área de texto e botão de envio;
- uso do atributo `name` para identificar dados submetidos.

## Arquivo e execução

O arquivo `index.html` contém todo o exemplo. Basta abri-lo no navegador. O formulário é didático e usa `action=#`, portanto não envia dados a um servidor.
