# HTML — Títulos e textos

Página de referência para elementos de conteúdo textual e para a hierarquia de títulos do HTML.

## Conceitos estudados

- níveis de título de `h1` a `h6`;
- parágrafos e quebras de linha;
- ênfase e importância semântica;
- organização de blocos de texto;
- listas e outros elementos usados para dar estrutura ao conteúdo;
- diferença entre aparência visual e significado semântico.

## Como visualizar

Abra `index.html` no navegador e observe como cada elemento recebe uma apresentação padrão. Inspecionar o código permite relacionar cada resultado à tag correspondente.
