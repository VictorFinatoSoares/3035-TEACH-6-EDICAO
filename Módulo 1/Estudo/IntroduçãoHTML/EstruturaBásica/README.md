# HTML — Estrutura básica

Exemplo mínimo de um documento HTML5. A atividade apresenta a base necessária para qualquer página web: declaração do tipo de documento, elemento raiz, metadados e corpo visível.

## Conceitos estudados

- `<!DOCTYPE html>` para indicar HTML5;
- `<html lang=pt-BR>` para definir o documento e seu idioma;
- separação entre `<head>` e `<body>`;
- codificação UTF-8 com `<meta charset=UTF-8>`;
- título exibido na aba do navegador com `<title>`.

## Arquivo

- `index.html`: estrutura mínima, com o corpo propositalmente vazio.

## Como visualizar

Abra `index.html` no navegador e observe o título da aba. O principal objetivo está na leitura da estrutura do código-fonte.
