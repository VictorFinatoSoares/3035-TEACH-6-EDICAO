# HTML — Tabelas

Exercício de organização de informações em linhas e colunas utilizando os elementos semânticos de tabela do HTML.

## Conceitos estudados

- criação da tabela com `table`;
- definição de cabeçalho e corpo com `thead` e `tbody`;
- agrupamento de células em linhas com `tr`;
- células de cabeçalho `th` e células de dados `td`;
- relação entre a ordem dos cabeçalhos e os dados apresentados.

## Arquivo e execução

Abra `index.html` no navegador. Não existem estilos externos, scripts ou dependências: o foco está exclusivamente na estrutura tabular.
