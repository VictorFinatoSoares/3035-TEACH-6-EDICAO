# CSS — Flexbox

Página de estudo do modelo de layout flexível. O exemplo organiza cartões com imagens de cidade, litoral e montanha, mostrando como distribuir e alinhar elementos em um eixo.

## Conceitos estudados

- ativação do contexto flexível com `display: flex`;
- eixo principal e eixo transversal;
- distribuição com `justify-content`;
- alinhamento com `align-items`;
- espaçamento com `gap`;
- quebra de linha com `flex-wrap`;
- dimensões e comportamento dos itens flexíveis.

## Estrutura

- `index.html`: contêiner e cartões;
- `style.css`: regras de layout e apresentação;
- `assets/`: imagens usadas nos cartões.

## Como visualizar

Abra `index.html` e redimensione a janela para observar como o conjunto se adapta ao espaço disponível.
