# CSS — Aplicação final responsiva

Aplicação prática dos conteúdos de CSS em uma tela de autenticação da plataforma fictícia **LingoWise**. O layout combina uma área visual com avatar e um painel de login.

## O que foi aplicado

- divisão da tela em seções;
- Flexbox para alinhamento e distribuição;
- gradientes, tipografia, cores e imagens;
- estilização de formulário, checkbox, links e botões;
- estados de interação;
- agrupamento de ações de login e cadastro;
- adaptação da interface para diferentes tamanhos de tela.

## Estrutura

- `index.html`: logo, apresentação, formulário e acessos sociais;
- `style.css`: layout completo e responsividade;
- `assets/avatar.png`: ilustração da área visual;
- `assets/icon.png`: ícone da marca.

## Como visualizar

Abra `index.html` e altere a largura da janela para observar o layout responsivo. Os controles são demonstrativos e não realizam autenticação.
