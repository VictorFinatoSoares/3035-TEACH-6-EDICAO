# CSS — Grid Layout

Exemplo compacto do CSS Grid para distribuir elementos em linhas e colunas bidimensionais.

## Conceitos estudados

- criação de um grid com `display: grid`;
- definição de colunas;
- espaçamento entre células;
- posicionamento automático dos itens;
- diferença entre um layout bidimensional em Grid e um layout orientado por eixo em Flexbox.

## Arquivos

- `index.html`: contêiner e itens do exemplo;
- `style.css`: configuração da grade e aparência das células.

## Como visualizar

Abra `index.html` no navegador e redimensione a janela para avaliar o comportamento da grade.
