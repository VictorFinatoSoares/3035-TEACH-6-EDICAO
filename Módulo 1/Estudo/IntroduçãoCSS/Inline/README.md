# CSS — Estilos inline

Exemplo introdutório de aplicação de CSS diretamente em elementos HTML por meio do atributo `style`.

## Conceitos estudados

- sintaxe de propriedade e valor;
- aplicação de cor, tamanho, espaçamento e outras regras em um elemento específico;
- prioridade do estilo inline na cascata;
- diferença entre CSS inline, bloco `<style>` e arquivo externo.

## Observação

O estilo inline é útil para demonstrar regras isoladas, mas tende a dificultar reutilização e manutenção em páginas maiores. Os estudos seguintes separam a apresentação em `style.css`.

## Como visualizar

Abra `index.html` e compare o resultado visual com os atributos `style` presentes na marcação.
