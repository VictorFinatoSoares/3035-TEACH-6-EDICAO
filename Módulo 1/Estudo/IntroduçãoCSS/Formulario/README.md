# CSS — Estilização de formulário

Exercício que transforma um formulário HTML em uma interface visualmente organizada por meio de um arquivo CSS externo.

## Conceitos estudados

- seletores de elementos, classes e estados;
- organização vertical de rótulos e controles;
- dimensões, margens, preenchimentos e bordas;
- tipografia e paleta de cores;
- estilização de inputs e botão;
- estados de foco e interação;
- centralização e criação de um painel para o formulário.

## Arquivos

- `index.html`: estrutura e campos do formulário;
- `style.css`: regras responsáveis pela apresentação.

## Como visualizar

Abra `index.html` no navegador. O formulário é apenas visual e não possui processamento de envio em JavaScript ou servidor.
