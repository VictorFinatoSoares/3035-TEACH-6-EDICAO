# JavaScript — Exercícios introdutórios

Arquivo de estudos com três grupos de exercícios de lógica, funções e manipulação de coleções. Os resultados podem ser observados habilitando as chamadas de `console.log` e executando o script.

## Exercícios

### 1. Conversão de temperatura

Funções convertem Fahrenheit para Celsius e Celsius para Fahrenheit, praticando parâmetros, retorno, cálculos e template strings.

### 2. Estatísticas semanais

Um array de temperaturas é analisado para obter menor valor, maior valor, média e quantidade de dias abaixo da média. São usados `Math.min`, `Math.max`, spread, `reduce` e `filter`.

### 3. Biblioteca de livros

Uma lista de objetos representa livros. Funções permitem adicionar um registro, buscar por autor e alterar o ano de lançamento, exercitando `push`, `filter` e `find`.

## Arquivo

- `script.js`: contém os dados, funções e chamadas de teste comentadas.

## Como executar

Use o console do navegador ou um ambiente JavaScript como Node.js:

```bash
node script.js
```

Descomente as chamadas de `console.log` desejadas para visualizar os resultados. Não há dependências externas.
